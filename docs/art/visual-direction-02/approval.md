# Ford Frenzy art direction approval

Owner approval on 2026-09-07: "awesome, locked in", responding to the
GTA IV loading-screen inspired [newsroom concept](newsroom-concept.png).
The exact approved image hash, dimensions, tool and prompt are in
[generation.json](generation.json).

Approved: muted olive/slate/tan/rust colours, heavy ink, angular grounded adult
faces, casual staff clothing, scrappy Toronto newsroom and satirical tone.
No anime faces, default suit-and-tie journalist costumes or excessive dirty clutter.
GTA IV is a visual reference; characters, branding and game assets remain original.

This supersedes visual direction 01 and the intermediate flat-graphic/GTA V
experiments as the production style guide. The earlier concept and provenance
are preserved. Brighten playable scenes and verify object separation/readability.
Approval covers the style, not final character identities, exact target placement,
UI acceptance, source rights, release exports, runtime rendering or pipeline proof.

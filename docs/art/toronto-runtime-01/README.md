# Toronto runtime environment 01

#143 derives this clean background plate from the owner-approved #142 composition.
The built-in image tool removed the mockup HUD, foreground characters and six
collectible props. Source and generated pixels remain unchanged. This is a
fictional Toronto newsroom, not a surveyed historical location. Release rights
and final art approval remain separate.

The renderer loads this plate as S01.BG01. Existing hash-verified collectibles
remain separate textures from pipeline-proof-01, and optional dialogue portraits
remain separate from dialogue-01. Production HUD and mission lettering are live
controls/text, never painted into this background. Prompt and provenance are
adjacent. The historical proof manifest is preserved; current placement belongs
to games/ford-frenzy/data/s01.json.

Only presentation positions change. Stable object/content IDs, action sequence,
progression rules and the save revision remain unchanged. Saves replay object-ID
actions, not coordinates, so existing progress and hints retain their meaning.
An interrupted opening reloads into the existing search/continue flow; dialogue
position remains transient. This is not a general coordinate-replay migration.

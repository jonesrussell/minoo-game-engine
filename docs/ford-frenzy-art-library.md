The complete archive stays outside Git, with source-index.json, originals and the
private review inventory. Drive originals remain intact. The repository contains
sanitized IDs/hashes/classifications and only two reference exports (about 1.6 MB).
Do not reorder the source index: IDs are frozen for this import. Append new entries.

with the owner archive; restore sources by ID and verify every SHA-256.

Creator attribution and release approval are not inferred from Drive ownership.

only in the private archive. Contact-sheet review does not constitute owner approval.

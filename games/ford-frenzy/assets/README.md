# Legacy artwork library

The inventory contains 113 source records with immutable IDs, SHA-256 hashes,
dimensions, PSD layer metadata, duplicate links and reuse classifications.
Full sources are preserved in the owner's external archive, not the game bundle.

`reference-manifest.json` indexes the two owner-directed authoring references in
`references/`. These are not runtime-loaded or release-approved assets. Do not
interpret the inventory as the runtime manifest contract from #37.

No scene, package entry or renderer is created by this directory. #105 creates the
playable game entry. #94/#104 select and adapt references; #17 approves final art.
The preserved source assets are not relicensed by the repository's code license.

See [the import report](../../../docs/ford-frenzy-art-library.md).
